# c-net
Various example projects demonstrating network programming in c.

## Example

```shell
# Clone the repository
git clone https://github.com/forletta/c-net.git

# Navigate to the project directory
cd c-net

# Build and run the client (googles ip)
make client
./build/client 142.250.68.14

# Build and run the server
# In your browser go to localhost:8080
make server
./build/server
```
